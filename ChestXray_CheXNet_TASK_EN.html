Project Task — Chest X-ray Disease Detection (CheXNet)

Build a model that reads a chest X-ray, predicts diseases, explains itself, and lives in a real web app.

Individual / pair project Mid-level computer vision Real paper + real dataset Free tools · weak laptop OK
Medical disclaimer (must be in your submission): this is an educational project. Your model is NOT a medical device and must never be used for real diagnosis.
Your goal: reproduce the core of CheXNet — given a chest X-ray, predict the probability of 14 thoracic diseases, show a heatmap of where the model looked, and deploy it as a real web app (your own frontend + a backend API).

What you must build

  1. Load the data & labels. One X-ray can show several diseases → this is a multi-label problem (14 yes/no outputs), not pick-one.
  2. Split by PATIENT, not by image. The same patient has many X-rays — if you split by image, your score is fake. Split so no patient is in both train and test.
  3. Train a model with transfer learning. Start from a network pre-trained on ImageNet and adapt it to X-rays (this is what CheXNet does).
  4. Evaluate with per-disease AUC-ROC — not accuracy (the data is very imbalanced). Compare your numbers to the paper.
  5. Add Grad-CAM heatmaps — show where on the X-ray the model looked.
  6. Build a REAL web app and deploy it. A backend API that serves your model + your own frontend (upload an X-ray → see predictions + heatmap). Deploy both so anyone can use the link.
Deployment rules (important):
